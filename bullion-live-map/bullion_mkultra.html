    Privacy

    This site sets no cookies, uses no analytics, and collects no personal data. It loads live market data from a data.json file and news headlines from a news.json file, both served from this same site and refreshed by an automated pipeline. The macro analysis feature and the news bar's bullish/bearish tagging both run as deterministic, local calculations — no request, state, or API key is ever sent anywhere for either. The page is hosted on GitHub Pages, whose provider may process your IP address to serve it, under its own privacy policy.
